CAOS LIVE - SNOW FROST PUZZLE PACK

Este pack NAO e um conjunto de tiles aleatorios.
Ele contem CHUNKS PRE-MONTADOS de 512x512 px.

REGRA DE ENCAIXE
- Cada lado e "path" ou "closed".
- Norte encaixa com Sul.
- Leste encaixa com Oeste.
- path so encaixa com path.
- closed so encaixa com closed.

MASCARA
N=1, E=2, S=4, W=8.
Exemplos:
5  = caminho vertical N+S
10 = caminho horizontal E+W
3  = curva N+E
15 = cruzamento nos 4 lados

CONTEUDO
- 16 mascaras completas
- 2 variacoes por mascara
- 32 chunks no total
- objetos ja compostos
- colisao normalizada no manifest.json

Para o jogo, carregue manifest.json, filtre as pecas compativeis com os vizinhos
e escolha uma das variantes correspondentes.
